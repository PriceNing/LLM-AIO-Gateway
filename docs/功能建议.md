# LLM AIO Gateway 功能建议

按小工具、个人向的定位过滤，以下功能按优先级整理。

## 已实现（原“必要功能”部分已落地）

### 1. 请求/响应查看器 ✅
- `request_logs` 表已存在，记录 endpoint / username / api_key / requested_model / model / provider / status / stream / tokens / request_body / response_body / details / error。
- `app/router/proxy.py` 四个端点（`/chat/completions`、`/completions`、`/messages`、`/responses`）以及生图端点在成功 / 失败 / 取消路径都调用 `_log_request()` / `_record_request_log()` / `_build_stream_recorder()` 写入。
- Admin API：`/admin/request-logs`（列表）、`/admin/request-logs/{id}`（详情）、`/admin/request-logs/{id}`（DELETE）、`/admin/request-logs/clear`（清空），均支持 `endpoint` / `username` / `status` 过滤。
- Admin SPA 在“系统日志”侧边栏提供“请求日志”子页，渲染 JSON 高亮 + 折叠。

### 2. 导出/导入配置 ✅
- `/admin/config/export` 返回 JSON，默认脱敏 api_key；`?include_secrets=true` 可携带密文。
- `/admin/config/import` 接受 JSON，按 `skip` / `replace` / `merge` 三种模式合并 providers / preprocessors / image_generators / routing_rules / fallback_policies。
- 导入路径有 `_validate_imported_upstream_urls` 统一做 SSRF / 上游地址校验。
- 用户与 API Key 也提供对应的 `/admin/users/export` 与 `/admin/users/import`。

## 差异化功能（待评估）
