# LLM AIO Gateway 功能建议

按小工具、个人向的定位过滤，以下功能按优先级整理。

## 必要功能

### 1. 请求/响应查看器
- 现状: `request_records` 表只记了 model/username/success/tokens，admin 面板 stats 页能看到聚合，但看不到某条具体请求的完整 body。
- 目标: 在 admin 面板加一个"最近 N 条请求"列表，点开看完整入参/出参/routing 详情/错误信息。
- 落地:
  - 新增 `request_logs` 表。
  - `app/router/proxy.py` 在四个端点的成功/失败路径统一调用 `_log_request_detail()` 写入。
  - 新增 `/admin/request-logs` 列表/详情/清空/按 endpoint 过滤 API。
  - admin SPA 新增"请求日志"侧边栏，渲染 JSON（高亮 + 折叠）。

### 2. 导出/导入配置
- 现状: `providers / routing_rules / fallback_policies` 只能一条条手动加。
- 目标: admin 面板增加"导出配置"和"导入配置"按钮，生成一个 JSON 文件。
- 落地:
  - 新增 `/admin/config/export` 返回 JSON（默认脱敏 api_key）。
  - 新增 `/admin/config/import` 接收 JSON，按策略（skip/replace/merge）处理。
  - admin SPA 在"系统设置"区块放两个按钮 + 一个策略下拉。

## 差异化功能

- Anthropic Prompt Caching 透传 + 命中率统计
- 可配置超时/重试
- 精确匹配响应缓存
- Prompt 模板库 + 变量插值
- 本地 Ollama 适配器
- 多模态扩展（PDF、音频）
- Token 用量看板 + 单价换算
- 轻量 A/B 对比

## 可以跳过的

多租户、SSO、审计日志、Webhook、自动评测、Helm chart、SDK 矩阵、批处理 API、影子流量、限流、配额、计费、Prometheus 全部跳过。
